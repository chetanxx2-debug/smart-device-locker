Step 2: Set Screen Time Lock (Retailer Only)

Retailer ke liye: Profile install karne ke baad, customer ka phone lock karne ki power aapke paas hogi. Neeche Screen Time passcode set karein — sirf aap jaano, customer ko mat batana.

1. iPhone Settings → Screen Time → Turn On Screen Time
2. "Use Screen Time Passcode" → 4-digit code set karein (sirf aap jaano)
3. "This is My Child's iPhone" choose karein (more control milta hai)
4. Downtime → Always On karein. Allowed Apps mein sirf Phone allow karein
5. EMI miss hone par → Dashboard → Lock Device → iPhone ka Smart Locker WebClip lock screen dikhayega

Important: Apple iOS mein Screen Time passcode sirf physical access se set hota hai. Hamare dashboard se Lock Device dabane par customer ke iPhone ke Smart Locker app mein lock screen dikhega — yeh 8 seconds mein automatic ho jata hai, bina kisi action ke.
